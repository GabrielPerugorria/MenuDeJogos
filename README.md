## 📌 Sobre o projeto

O **Gabriel Games (GG)** é uma plataforma web desenvolvida para centralizar minigames em uma interface moderna e imersiva, trazendo uma experiência gamer com sistema de perfil, progressão por níveis, XP, conquistas e ranking.

O objetivo do projeto foi criar uma aplicação divertida, responsiva e visualmente atrativa, simulando a experiência de um pequeno ecossistema gamer dentro do navegador.

Além dos jogos, o usuário pode personalizar sua experiência com configurações de tema, áudio e animações, tornando a navegação mais dinâmica.
